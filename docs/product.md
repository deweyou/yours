# 产品定义

产品名称：**Yours**。品牌标语：**Yours. Truly yours.**

## 已确认方向

Yours 是统一的个人工作空间，核心定位为写作、备忘和待办。技术、界面和交互重新设计。

- 日程、纪念日、个人 Agent 和 Memory 是后续探索方向，具体功能与数据边界待设计，尚未实现。
- 使用 Swift 原生技术，面向 Mac、iPad 和 iPhone，保持单仓库。
- 数据由 App 管理，本地优先，通过 CloudKit 同步；不以用户管理的 Markdown 文件夹作为主要存储。
- 同一 Apple 账户的新设备可恢复已上传内容；未上传数据仍依赖原设备。
- 记录可以嵌入画板与思维导图预览，进入独立编辑区修改可编辑内容。
- 多设备同步服务于个人连续使用；实时多人共同编辑不属于当前确认范围。

当前已实现本地富文本编辑和可选 CloudKit 同步的代码接入；Mac 开发环境的真实上传与重启后同步已验证，生产环境与双设备同步仍待验收，画板尚未实现。

## 已确认工作区结构

Mac 使用「底板功能栏 + 双栏卡片」：首页、文档、任务入口位于底板上方，设置位于底部，文档卡片内部为 Inbox 文件夹侧栏与内容区；Inbox 显示全部现有文档，不改变笔记归属，首页暂留空态。iPad 宽窗口保留「综合侧栏 + 内容区」，功能入口位于侧栏上部，下部为该功能独立的分类与常用视图。记录和任务不共享分类。平台共享信息架构，窄窗口 iPad 与 iPhone 对齐，按可用空间适配。布局和材质边界见 [DESIGN](../DESIGN.md#工作区布局已确认方向)。

当前 Mac 保留直接浏览笔记、新建、编辑及基础设置，移除分类、搜索、Markdown 文件导入和顶部工具栏，后续需要时单独设计。已有笔记与分类数据保留。iOS/iPadOS 的分类、搜索和导入入口保持现状。独立任务和折叠屏专项适配仍为后续方向。

基础设置包括浅色、深色、跟随系统，以及中文/英文应用语言。主题立即生效；切换语言需确认，Mac 保存后自动重启，取消不修改语言。移动端确认后手动重新打开，笔记内容不翻译。「数据与同步」提供默认关闭的 iCloud 开关、同步状态与当前资料库说明。关闭同步保留本地和云端已有内容；未配置授权的构建仍可本地使用。

## 待设计与验证

图片与附件尚未支持，接入时一并实现按需下载、图片缩略图与「保持图片和附件下载」；正文及未来待办文本保留本地，暂不引入正文卸载。具体下载、清理与关闭同步流程见[后续空间管理方向](storage-and-sync.md#图片与附件的空间管理已确认方向尚未实现)。各功能细节和回收站保留策略仍需后续设计。Markdown 文件导入目前仅保留移动端入口；Mac 保留正文快捷语法和粘贴解析，并在文件菜单提供 Markdown 复制、导出。公式与 Mermaid 通过 Markdown 粘贴或导入识别，正文显示最终结果，点击编辑源码。
详见[第一版交互草案](specs/first-release.md)。用具体流程与验收场景收敛问题，避免一次性扩展成完整办公套件。
