# 验证与证据

## 独立任务 MVP

`TodoLibraryTests` 覆盖完成父任务前的明确选择、取消/只读、恢复祖先、深层移动防环、子树归属、软删除与 15 天到期内容清理、旧设备不能复活过期记录、恢复降级、当天 DDL/跨午夜时段、富文本重启及混合状态撤销。`CloudLibrarySyncTests.taskPayloadUsesExistingCheckpointAndWaitsForOpenTaskEditor` 用替身验证任务快照上传、编辑保护、远端合并和本地落盘，不证明真实 CloudKit 已通过。

实际 App 使用独立测试资料库：创建中文任务 → 新建子任务 → 备注粘贴 checklist → 勾父任务选择剩余项不做了 → 单独恢复子任务并检查祖先恢复 → 设置计划日、DDL 和两段时间 → 删除/回收站恢复 → 正常退出重启，检查内容、状态和时间。检查 All/Today/项目切换、详情返回、取消后的只读和保存错误。移动端软键盘、输入法组合、无障碍和真实同步分别验收。

属性条回归：标题 → 属性条 → 子任务 → 备注；无安排/单段/多段、跨日摘要、独立截止、添加属性菜单、铃铛直接编辑单段/选择多段、编辑浮层移除与撤销、只读多段可查阅；属性随宽度换行。属性条中原生 Menu 与 Button 必须对控件外层设定相同行高及居中，不能只给 Menu 的 label 设置 frame；检查空任务铃铛/加号、单段与 +N、多段提醒的图标中心一致。图标按钮检查 Tooltip、可访问名称、键盘操作和触控热区，不能仅靠图标表达日期值或确认动作。

整版设计回归：无详情宽窗的阅读列应居中且有一致外边距；有详情、紧凑窗口下标题与行背景仍共享容器。主列表长标题最多两行且 Tooltip / AX 保留全文，详情可完整编辑；整行真实 hover、选中、键盘焦点分开截图。通过任务标题焦点实测上下移动、左右展开/收起/父子切换、Return 打开、可见区域跟随；聚焦快速输入框时方向键不导航任务，输入不被抢占。

整页几何走查需同时截取三栏：侧栏两处分隔的累积空白、项目标签/加号中心与字号；主列表页面标题与行背景整体左边界、项目/任务/快速录入的文字列、长标题距行背景右边缘的至少 16 pt 留白与展开/勾选热区；详情路径/标题/分区/备注的文字起点、工具栏距右沿、属性图标间距和分隔线上下累积空白。不能只凭局部控件对齐判定整页通过。

任务设计细节每次修改后应整组走查：单行/多行标题的框与首行字形居中、选中背景上下留白；项目组标题/任务/快速录入共用文字列；侧栏长名称首行对齐；详情标题/备注/分区标题共用文字起点；空备注 placeholder 与光标、短备注自然高度、长备注滚动及文末空行光标；子任务与添加行文字对齐；多段及跨日时间的日期首行/移除按钮、截止日期窄栏换行；滚动后路径/关闭按钮仍可见。覆盖空态、选中、已结束、回收站、浅深色和窄窗口；没有实际截图与操作证据的状态保持待验证。

范围与时分回归：连续两次点击、翻月至下一月/年选择结束、同日范围、第二下更早时重选开始、第三次开启新范围、取消待完成端点；跨行/跨月浅色范围条与实色端点；小时/分钟分别下拉且保留日期，起止和提醒一致；范围模式方向键仅移动，空格/回车确认端点；翻月后键盘焦点留在可见月份。仅选开始日后切换开始/结束/提醒仍禁止保存；仅查看已有结束日允许不修改直接保存。检查日期行长日期/英文换行、统一水平边距、紧凑底部按钮，以及六周月历和提醒展开后滚动且头尾不被裁切。

自绘月历还需检查完整周网格、相邻月/跨年、闰年二月、四/五/六周高度、周一列起点、夏令时跨日及切日保留时分；方向键跨月、禁用日期、选中态与可访问完整日期。

日期浮层回归：安排和截止共用快捷日期/月历；下周为下一个周一；日期选择保持开始时分和执行时长，允许结束跨日；结束不早于开始后一分钟；结束日和提醒日切换同一月历并显示当前编辑字段；新建/已有安排的取消、点外部与 Escape 不保存；完成后可重新打开，新增多段不替换已有安排；截止选择不改变安排；只读状态不能打开编辑；宽窄窗口浮层不裁切，提醒权限仅主动启用时请求。

任务设计与交互修订还需覆盖：Today/项目下按钮和 ⌘N 新建归属一致；快速添加连续录入不打开详情；完成框无实色内底、三态明确、热区按平台区分；详情三个分区共享文字起点、各级关闭与删除后返回；取消前后备注检查项/表格/附件保持相同呈现且可复制、不可修改；状态撤销保留后续备注及无关任务编辑，冲突有反馈；非法结束时间不可选、时长明确；午夜/时区/回前台的 Today 更新；移动同名路径搜索；回收站原位置、到期时间、恢复实际位置。主列表通过独立按钮暴露打开与完成，分别用键盘/VoiceOver 操作，不以 AX 标签存在代替可用性验收。

## 本地存储与可选 iCloud

运行 `swift test --filter 'AppStorageTests|CloudLibrarySyncTests|NoteStoreTests|AppPreferencesTests'` 验证资料库隔离、重建恢复、开关持久化、合并去重、账户绑定、关闭时丢弃旧结果和失败重试。打开文档的多窗口登记需要覆盖：远端修改不替换任何仍打开的编辑器，最后一个窗口离开后恢复合并，本地独立修改仍可上传。

Mac 普通 Debug 启动使用固定开发资料库：输入标题与正文后 Command-Q，确认进程结束，再正常启动并从 Inbox 打开，核对最后输入。测试会话使用固定 UUID 重启；Release 忽略测试环境变量。设置页检查资料库名称、未配置授权的禁用说明、开启后的状态、错误与立即同步；新增控件继续遵循 pointer 验收要求。

真实 CloudKit 的 Team、容器、环境、schema 与双设备矩阵见[存储与同步](storage-and-sync.md)。离线替身测试、ad-hoc App 和平台编译不能作为云端同步成功证据。

从工作区根目录运行。按实际改动选择检查，结果注明提交 / 差异、平台、命令、退出码及未验证项；不要长期写死测试数量。

## 原生 UI 设计验收

设计要求见 [Apple 原生界面设计规则](../.agents/rules/apple-native-design.md)，按其第 12 节选择受影响的验收维度。圆角和边距修改除截图外，核对容器形状来源、实际累计 inset、正常/全屏/平铺状态与底部错误栏出现时的关系；显式容器半径不能视为系统窗口实时半径。未测场景逐项注明，不以构建成功代替视觉和输入验收。

## 可点击区域的指针验收

所有涉及按钮或可点击区域的 UI 改动，必须按 [设计约定](../DESIGN.md#可点击区域的光标全局约定) 检查 pointer（手型）：

- 在 macOS 上实际移入图标中心、文字和完整点击热区边缘，均应显示手型；有指针的 iPad 场景检查对应交互反馈。
- 检查按钮、菜单触发器、导航项、卡片、链接、开关、原生编辑器内嵌控件和浮层操作，不能仅凭 SwiftUI 修饰符或编译通过判定生效。
- 移入禁用控件或不可点击背景不应显示操作手型；文本输入、选区和调整大小区域保留各自语义光标。
- 移出、隐藏、删除、切换页面、Toast 自动消失或点击关闭后不残留手型；相邻控件之间移动保持正确。
- 确认光标处理不拦截点击，不抢键盘焦点，不影响文本光标和选择。无法通过工具实际验证指针外观时，明确记录待人工验证，不写成已验收。

## Slash 与选区格式回归

`EditorCommandContractTests` 检查中文/英文别名、UTF-16 查询范围、普通路径与空白退出、已完成任务的幂等转换、完整代码范围、半开段落选区与清除文字格式后的存储语义。原生桥接测试补充组合输入保护、撤销/重做与后续输入；输入法标记测试不等于真实候选窗口实测。

UI 回归使用独立 bundle ID 与 Debug 隔离 UUID 存储，不终止其他工作区的用户实例。Mac 检查：输入 `/h2` → 转换 → 撤销/重做 → 输入标题与下一段 → 重启恢复；Esc 保留查询，无结果 Return 正常换段；选区点击加粗后继续输入替换原选区；链接取消、应用、重新打开与替换选区。移动端检查 slash 触控选择及后续输入；系统选区菜单、链接面板、软键盘/硬件键盘切换分别复核。

人工补充：真实中文输入法组合与候选回车、跨行反向拖选、滚动中浮层定位、长文与窄窗、列表缩进、表格尺寸与退出、浅深色、VoiceOver、减少透明度和完整点击热区的手型。程序选区恢复不应抢焦点；切换记录或编辑导致目标过期时不能改写新目标。

本段是可复用验收方法，具体通过项以当前任务的测试日志和交互证据为准，不将构建通过或静态截图当作全部交互通过。

行内代码选区需验证实际填充：`ReadingLayoutTests.nativeSelectionFillExcludesCodeSurfacePadding` 通过原生 `drawBackground` 渲染位图，比较选择前后的像素，确认文字区域出现高亮、代码末尾留白不出现高亮，覆盖非零文本容器 inset。仅检查 `enumerateEnclosingRects` 返回值不能证明 AppKit 的实际选区高亮正确；仍需在 App 中检查激活与失焦选区、跨行拖选及代码边界点击。

## 自动检查

App 图标修改：运行 `python3 scripts/generate_app_icons.py` 与 `--check`，确认主 SVG 与 `.icon` 图层同步；预览 `.build/app-icons/preview.html` 中浅深色、Clear / Tinted 和缩小图。随后构建 Mac / iOS target，检查产物 Info.plist 的 `AppIcon` 引用、Mac 的 `AppIcon.icns`、iPhone/iPad 的图标记录与 Assets.car 内各外观的图标栈。当前矢量版已通过两平台构建及资源检查，原生导出图已查看。Mac 已启动使用独立 bundle identifier 和沙箱的本地图标预览，在“关于 Yours”中确认新图标实际加载且三角形与水滴可辨；原有工作区实例保留。Dock 截图读取超时，Dock / 主屏幕、不同壁纸、真机和系统着色设置尚待实测。

| 影响范围 | 命令 / 检查 | 能证明什么 |
| --- | --- | --- |
| Swift 格式 / 静态风格 | `swift format lint --recursive --strict --configuration .swift-format Sources Tests UITests Package.swift` | Swift 源码符合仓库格式与基础静态规则 |
| Swift 行为 / 数据修改 | `swift test` | 现有测试覆盖的规则、存储与桥接行为 |
| Mac 代码与共享代码 | `xcodebuild -project Yours.xcodeproj -scheme Yours -destination 'platform=macOS' -derivedDataPath .build/xcode CODE_SIGNING_ALLOWED=NO build` | Mac target 编译 |
| iOS 代码与共享代码 | `xcodebuild -project Yours.xcodeproj -scheme Yours -destination 'generic/platform=iOS Simulator' -derivedDataPath .build/ios CODE_SIGNING_ALLOWED=NO build` | iOS Simulator target 编译 |
| 文档 / 配置 | 本地链接、入口、源码一致性；Harness `config_inspect` | 文档和配置有效，不证明 App 行为 |
| 交付差异 | `git diff --check`；暂存后 `git diff --cached --check` | 空白与差异检查，未跟踪文件需另查 |

首次使用需 Xcode / Swift 6.2 兼容工具链。沙箱中的宏插件或编译缓存权限失败属于环境问题；明确报告并走宿主授权，不把关闭沙箱作为仓库默认命令。日志和构建产物放 `.build/` 或任务临时目录，Run 中按需记录 Evidence。

Mac 实际预览使用 `xcodebuild -project Yours.xcodeproj -scheme Yours -destination 'platform=macOS' -derivedDataPath .build/xcode CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO build` 做本地 ad-hoc 签名，保留工程的 App Sandbox 配置。`CODE_SIGNING_ALLOWED=NO` 只用于编译验证；直接运行无签名产物可能改用非容器 Application Support，不能据此判定原笔记丢失。重启按 AGENTS 的单实例规则操作，先核对会话、保存状态与实际数据目录。

引用内代码块还需检查语言选择栏与代码背景左右边缘一致，语言标签与正文共享内部左边距；普通代码块和宽窄窗口分别验证。

## 验收边界

Mac 文字布局调整需检查中文、英文、空段、标题、跨行选择、emoji、代码块首行及表格附件；文字基线和下方段落位置应保持不变。几何回归与实际 App 截图分别记录，原生光标与选区几何通过 TextKit API 检查，并在 App 中验证焦点、移动和闪烁，不用自定义绘制辅助函数作为验收依据。

非首段标题要单独检查段前留白：六级标题在宽窄窗口与折行后，原生光标/选区应包住当前行文字，不能因为规范化行高或基线而漏算段前间距。N01 嵌套样本用于覆盖标题及正文粗斜体/删除线边界。链接检查默认灰色下划线与文字的距离、引用内颜色继承、换行和原生下划线组合；macOS 悬停仅当前链接变为主题色文字与实线，移出平滑恢复、编辑后立即清除，检查快速移入移出连续过渡及减少动态效果设置，装饰间距保持一致，不得改变正文、光标几何或持久化格式。

没有操作证据的项目写“待验证”；模拟器编译不等于模拟器运行，更不等于真机通过。单元测试对 marked text 的布尔保护不等于真实中文输入法通过。截图不等于撤销、保存或选择行为通过。

当前没有 CloudKit。将来同步验收必须覆盖离线修改、不同设备冲突、账号与配额问题、恢复与重试，并记录真实多设备证据。同步不替代备份。

`.github/workflows/ci.yml` 在每次 PR、main 推送及手动触发时运行，采用 GitHub `macos-26` 镜像和 Xcode 26.2。工具链变更需重新核对覆盖率和 UI 基线；镜像清单见 [GitHub runner-images](https://github.com/actions/runner-images/blob/main/images/macos/macos-26-arm64-Readme.md)。

- `Unit tests and coverage`：运行 Swift 测试与 Python 覆盖率门禁自身测试，保留日志、LLVM JSON 和 Markdown 汇总。
- `UI tests (macOS)` / `UI tests (iOS)`：运行 `YoursUITests`，保存 `.xcresult`（包含截图）和日志。iOS 自动选择可用的 iOS 26 及以上 iPhone 模拟器，不绑死设备 UUID。
- `CI required`：汇总检查；上游失败、取消或跳过都不能通过。仓库分支保护需要将此检查设为必需；仅添加 YAML 不会自动修改 GitHub 分支保护。

本地单测和门禁：

```sh

swift test --enable-code-coverage
python3 scripts/check_coverage.py "$(swift test --show-codecov-path)"
python3 -m unittest discover -s scripts -p 'test_*.py'
```

行覆盖率下限在 `scripts/check_coverage.py` 集中定义：核心逻辑 90%、原生桥接 55%、全源码 35%。UI 组包含 App 入口、AppSettingsView、WorkspaceView、MacWorkspaceView、MobileWorkspaceView、NativeTableView、NativeEditorControls 和 Toast；ToastPresenter 仍归入核心逻辑组。桥接组包含 NativeRichTextEditor、NativeTextAttributes、NativeTableOverlay 与 NativeRecordGallery。核心包含除这两组以外的全部 Swift 文件，新增文件默认纳入；当前平台编译的全部文件均计入全源码。报告缺失、源码缺项、重复条目或非法计数直接失败。门槛基于起步实测，不能把全源码 35% 描述成全项目 90%；后续扩大测试后应提高门槛，不因失败自动降低。

Package 单测运行在 Mac，覆盖率脚本默认 `--platform macos`：明确列出且排除整个文件受 `#if os(iOS)` 包裹的 `App/MobileWorkspaceView.swift`；`--platform ios` 对应排除 Mac 专属工作区文件。平台专属映射以完整相对路径列举，其他新增文件仍须有报告。移动端工作区行为由 iOS UI 测试验证，不能将 Mac 单测覆盖率当作它的覆盖率。

当前覆盖率来自单测，不混入 UI 执行数据；不提供分支覆盖率或新增行覆盖率门禁。UI 测试通过是独立检查，也不等于截图像素回归通过。

## Markdown 粘贴样本

打开 [markdown-paste-sample.md](examples/markdown-paste-sample.md) 的源码视图，全选复制原始文本，新建记录、进入正文后正常粘贴（Mac Command-V；iOS/iPadOS 使用系统粘贴）。不要复制 Markdown 预览网页的富文本；带 RTF/HTML 的剪贴板优先保持系统格式。样本不含图片或 HTML，下划线需单独从格式菜单设置。

检查六级标题、强调与链接、多级列表、勾选、引用嵌套、三种代码块、两张表格和中英文 emoji；整次撤销/重做、替换包含 emoji 的选区、继续输入、切换记录和重启。再次粘贴后检查两个副本的表格与代码操作相互独立。普通文本应保留原换行，代码内粘贴 Markdown 应保持字面量，选中文字粘贴 URL 仍创建链接。

## 列表标记与正文选区

### 输入与富文本组合矩阵

`NativeInputTests` 的参数化用例覆盖三类列表的快捷创建、顶层及嵌套空项互转、正文后语法不误触发、0/1/2 级续项、空项回车退出、逐级退格及合并、行中拆分、勾选状态保留、缩进上限、撤销重做、UTF-16 emoji 替换和 marked text 期间不转换。退出空列表应清除其前导 Tab；修改已完成待办的缩进应保留完成状态。

富文本回归包含六级标题创建/回车/行首退格、正文/标题/引用/三类列表内的加粗/斜体/删除线/行内代码快捷输入与后续输入、格式化选区添加链接、行内转换撤销重做，以及引用内列表退出。`MarkdownFormattingTests` 覆盖 72 种段落与行内格式组合的原生桥接及 Markdown 往返、代码中保留语法字面量、下划线与粗斜体/删除线/链接的原生剪贴板往返。下划线没有 Markdown 标准语法，不把 Markdown 往返列作其验收条件。

这些原生输入和几何自动化运行于 macOS。iOS/iPadOS 的软键盘、触控选区与真实中文候选仍需各自操作验证；共享逻辑及平台构建通过不代表所有设备交互已验收。组合矩阵覆盖受支持的代表性组合，不宣称穷尽任意层级嵌套。

无序圆点使用随字号缩放的矢量圆形，有序编号使用系统字体单独绘制，二者都不占正文字符位置。检查正文全选、跨段选择和光标左右移动，标记不进入字符选区；检查单行与折行、中文/英文/emoji、引用内列表与嵌套缩进。正文起点退格先减少缩进、再退出列表，不删除首字；回车续写、空项退出、Tab/Shift-Tab、撤销重做和后续输入均需回归。

旧记录加载前校验原投影，迁移后保存新属性；再次重启应保留内容及编号。Markdown 与应用内剪贴板仍保留列表语义，纯文本剪贴板回退使用 Markdown 标记。主级编号保留每项的值，回车递增；主级任意插入、删除后的整段自动重编号尚未实现。嵌套有序列表根据父项边界重新计数。

多级标记回归：无序前三层依次为实心圆、空心圆、方块，第四层循环；有序前三层依次为数字、字母、罗马数字。每个父项的子序列重新开始，兄弟项递增；检查缩进、减少缩进、引用内列表及 Markdown 往返。编号使用等宽数字并右对齐，文本选区仍不包含标记。样本包含四级有序结构。

列表光标边界：点击缩进区、行首键、左右方向键时，折叠光标不得停在列表前导 Tab 内。正文起点向左跳到上一段末尾；首段起点不越界。退格继续减少缩进/退出列表，跨段选区保留；普通正文和代码内的 Tab 不受限制，组合输入期间不修正选区。

列表快捷输入：在空文档、文末和已有正文前的空段分别输入 `-`、`*`、`+`、`1.` 再按一次空格，立即显示列表标记，光标位于正文起点；不需要第二个空格。继续输入中文/emoji、撤销重做，核对后续段落样式不被改变。

空列表首字几何回归：无序、有序和待办分别在空文档及已有正文前的空段输入快捷语法；比较输入首个中文字前后的标记位置与正文起点，不能出现横移。原生测试同时检查光标、标记的横纵坐标；待办的空项输入属性和换行边界都应立即带上列表缩进。

待办缩进与退格：空待办连续按 Tab/Shift-Tab 后，勾选框、光标和输入首字的位置应一致。非空待办回车续项后，退格先减少当前项缩进，无缩进时取消当前行待办并保留换行；再次退格才允许合并上一行。检查撤销、重做及继续输入正文。

空有序/无序续项：非空项回车后连续 Tab、Shift-Tab，圆点或编号始终可见；只含前导 Tab 的段落不能被当作已绘制标记。输入子项正文后，标记位置与层级保持一致。

## 代码块换行与横向滚动

复制左侧的自动换行按钮默认开启。分别关闭普通和引用内代码块，检查长行不折行、水平滑动仅移动当前块文字、语言与操作栏固定；第二个代码块和正文仍按各自宽度排版。重新开启应回到左端并恢复折行。检查横向与斜向触控板手势、惯性及 Shift+滚轮，正文视口横坐标始终为零，原生 `textContainerOrigin.x` 始终等于阅读内边距，不能随负坐标代码行自动补偿；长行末尾的原生光标自动滚动也不能带动整页。检查长中文/英文、文末光标、缩放窗口后的滚动边界，以及横向滚动后继续输入、选择、复制、撤销。换行是当前编辑视图的临时显示状态，重开记录恢复默认，不改变存储或 Markdown。

`ReadingLayoutTests` 覆盖引用/非引用长行、正文几何隔离、滚动和光标可见、恢复换行、窗口变宽后的偏移钳制与富文本不变。平台编译不能替代真实触控、组合输入和选区拖动验证。


## 代码块高度与纵向滚动

总高度上限 400 pt，包含工具栏和内边距。用 60 行代码、自然折行长行、短代码块、引用内代码和文末开放空行检查：块内上下滚动时工具栏、下方正文及另一块不移动；不换行时两个方向都只影响当前块；短块不预留 400 pt。滚动条仅滚动时显现，停止后淡出。

Mermaid 缩放验收：分别在正文和源码 sheet 的右侧预览用触控板捏合，检查以手势位置缩放、放大后双指滚动、边界 0.5–4 倍及正文段落高度不变；正文适应大小时滚轮仍滚动文章。编辑过程中预览更新保留缩放，取消不修改源码，应用可一次撤销。移动端捏合与系统手势冲突仍需设备验收。
