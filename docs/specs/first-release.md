# 第一期：原生文本编辑器与基础富文本

用户已收敛第一期范围：干净、简单的文本编辑，遵循 Apple 设计原则，使用系统控件与 Liquid Glass。

## 本期实现

- Mac 使用统一底板承载首页/文档/任务/设置功能栏，文档页右侧大圆角卡片内为 Inbox 文件夹侧栏与内容区。Inbox 显示全部现有文档，不改笔记归属，窗口顶部底板右上角「+」新建；右侧可浏览瀑布流或编辑，点击 Inbox 或功能栏「文档」返回总览。首页暂留空态。窗口左上角红绿灯后提供后退/前进，按窗口记录页面和文档访问历史，无历史时禁用。保留原生可拖动分栏，任务入口仍为规划说明，设置提供外观与语言偏好。
- Mac 移除分类、搜索、Markdown 文件导入、窗口顶部工具栏和正文格式栏。既有分类数据不删除，其中的记录仍可浏览、编辑与保存。相关功能后续独立设计。
- iPad 宽窗口显示综合侧栏与内容区，紧凑窗口按分类、列表、编辑分层导航；移动端保留分类、搜索、长按卡片或编辑页菜单移动、分类内新建与导入。
- 新建记录提供独立标题输入，空值显示 placeholder；长标题随宽度自动折行，Return 进入正文，粘贴的换行折叠为空格。标题可留空，正文不参与自动命名。旧记录将原首个非空行迁移为独立标题，其余正文和格式保持不变。导入 Markdown 使用文件名作为标题；导出时标题只用于文件名，不插入正文。
- 系统富文本原生编辑区、原生选区与编辑菜单；移动端保留格式菜单与字符统计。
- 移动端支持搜索记录；Mac Command-N 新建。
- 修改后本地原子保存，重启恢复；损坏文件禁写，保存失败提示重试。
- Mac、iPhone、iPad 共享源码，以系统 26 为当前基线。

默认主题色为系统蓝，通过 `AppTheme` 统一提供；主题色设置页为后续能力。导航与短暂错误 Toast 使用系统 Liquid Glass；正文不使用玻璃背景。读取出错保留源文件，只有明确的重新读取动作可以重试。

## 基础设置

- Mac 底部设置入口与 Command-逗号、iPhone/iPad 侧栏设置入口使用同一设置页。Mac 设置隐藏卡片内侧栏，内容限宽居中；主题和语言合并为一个「基础」分组。
- 主题支持浅色、深色、跟随系统，默认跟随系统；选择立即生效并在重启后恢复。
- 语言支持简体中文与英文，首次按系统语言选择；更改保存后在下次启动生效，设置页显示生效时机。应用自有文案、原生编辑器操作标签、错误提示与辅助功能标签使用本地化资源，系统菜单由应用语言偏好控制。
- 设置独立于笔记存储，不更改用户标题、正文、分类名称、富文本或 Markdown；第三方格式化器和系统返回的诊断详情保留其原始语言。

## 富文本增量

编辑器沿用原生所见即所得：输入快捷语法后就地排版，正文保持富文本主数据。Mac 移除常驻格式工具栏；移动端的常用段落、加粗、斜体、行内代码与列表放在正文上方工具条，完整格式仍在菜单中。以下文件导入、导出与菜单操作只描述移动端入口，底层共享富文本与 Markdown 编解码仍保留。

- 六级标题、正文、引用、代码块；加粗、斜体、删除线、下划线和链接。
- `~~删除线~~` 与既有加粗 / 斜体 / 代码闭合规则一致，可撤销；组合输入期间不自动替换。
- 空段落选择列表显示独立标记，不插入圆点或编号字符；菜单可对选中多段列表增加 / 减少缩进，最多八级，保留正文和行内样式。
- 侧栏的“导入 Markdown”读取 UTF-8 文件，创建新记录，不替换当前记录；读取失败显示错误。
- 正文普通粘贴支持外部纯文本 Markdown，复用文件导入解析器；没有已支持格式的普通文本走系统粘贴。应用内结构化内容优先，外部 RTF/HTML 保留系统行为，代码块和行内代码中不自动解析。粘贴替换当前选区，可整体撤销；标题和表格单元格仍是纯文本。
- Markdown 菜单可复制全文或导出 `.md` 文件。导出使用当前富文本的标题、列表、勾选、引用、代码、粗斜体、删除线和链接语义；普通标点转义，代码围栏根据内容选择长度。
- 导入和导出使用系统文件面板。导入后本地原子保存，沿用写失败重试与重启恢复。导出失败保留编辑内容并提示错误。

Markdown 是交换格式，不是整个富文本模型的无损备份：下划线、颜色、自定义字体和原始语法排版不会完全保留。图片和 HTML 没有结构化可视编辑。表格支持原位编辑单行纯文本、首行表头、增删行列、列对齐和 Tab 切换；合并单元格和单元格富文本不在当前范围。代码块保存语言标签，提供 26 种语言的基础词法高亮、复制代码、2 空格 Tab / Shift-Tab 缩进与回车续缩进；其中 12 种语言提供离线手动格式化与一次撤销，不支持的语言隐藏格式化按钮。具体支持表见架构文档。列表标记保存为段落属性并独立绘制，正文选区不包含圆点或编号，续写递增编号，但修改中间项目不会自动重编号，也没有独立待办模型。

正文默认段后距 6 pt，段内换行保持原行距。Markdown 导入将块间一个分隔空行转为段落边界，保留更多显式空段；连续正文源码行保留为段内换行，导出为 Markdown 硬换行。已有记录的空段不自动删除。

验收覆盖：空文档插入列表，多段缩进与 emoji 选区，闭合快捷语法后普通续写，导入生成独立记录并重启恢复，常用 Markdown 导出后再导入的文字与格式语义，失败时原数据保留。表格还需验证原位输入、末格 Tab 新建行、对齐、撤销、正文布局与重启；代码块需验证语言往返、首行为空、跨块选区缩进和字面量粘贴。真实中文输入法、移动端触控和 VoiceOver 仍需对应设备操作证据。

## Slash 与选区格式入口

正文提供可搜索 slash 命令与就近选区格式操作，复用六级标题、正文、列表、引用、代码块、表格和已有行内格式。Mac 使用临时浮层而不恢复常驻格式栏；移动端通过键盘附件候选、系统编辑菜单和详情面板适配。正文以外的独立标题字段不参与格式转换。

取消 slash 保留字面内容；转换段落时只移除本次命令。格式动作统一由原生编辑器处理选区、后续输入属性与一次撤销；链接编辑保留目标选区。目录搜索和面板状态仅存在于当前编辑会话，不增加笔记持久化字段。颜色面板、AI、评论和块拖拽不在本次增量范围。

交互规则与限制以 [DESIGN](../../DESIGN.md#slash-与选区工具栏) 和 [验证清单](../verification.md#slash-与选区格式回归) 为准；源码接入不代表所有平台输入法、触控和辅助功能已经验收。

## 验证

存储测试覆盖中文多记录恢复、稳定 ID、损坏文件禁写和写失败重试。Mac App 和 iOS Simulator target 分别编译。
真实交互应检查新建、输入、撤销重做、切换记录与重启恢复；中文输入法组合态、VoiceOver 和减少透明度需单独观察，不以编译代替。
当前 JSON 全量快照通过串行 actor 异步原子保存，用于小规模文本起步，不承诺大规模记录库性能或云端同步。


快捷语法和交互验收以[验证清单](../verification.md)为入口；具体实现边界见[架构](../architecture.md)。
